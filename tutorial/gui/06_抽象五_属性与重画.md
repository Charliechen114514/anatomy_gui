# 抽象 5/5 · 把"记得重画"变成做不到

> 第 2 步的最后一层，处理痛点 5：**状态改了界面不动。**

## 前身：改完就停手了

第 1 步里，点击处理是这样的：

```cpp
SetWindowTextW(g_label_hwnd, text);   // 系统控件：它自己会失效、自己会重画
lstrcpynW(g_drawn_text, text, 256);   // 我们自己的：改完就停手了
```

第一行会更新，第二行不会。原因是：`SetWindowTextW` 在内部把那个控件标成了"脏"，系统随后重画它；而我们只是把字符串拷进了一个变量 —— **没有任何人知道那块矩形需要重画。**

要让它更新，得再补一句 `InvalidateRect(hwnd, &g_drawn_rect, TRUE)`。我们**故意没写**，就是为了让这个坑显形。

## 痛点：正确性靠"记得"

这个 bug 的性质值得说清楚：**它不是逻辑错误，是遗漏。** 代码本身完全正确 —— 数据确实更新了，只是没人去画。

这类问题最麻烦的地方在于它**没有边界**：

- 每多一个"要显示的东西"，就多一处"记得要失效"
- 忘了不会报错，界面只是悄悄停在旧状态
- 写测试也难 —— 数据是对的，错的是"没发生的那件事"

所以正确的修法不是"下次记得写"，而是**让这件事不再是"要记得"的事**。

## 抽象：值自己会喊，节点自己会接线

**一个会通知的值**：

```cpp
template <typename T>
class Property {
public:
    using Listener = std::function<void()>;

    [[nodiscard]] const T& value() const;
    void set(T new_value);                  // 值真的变了才通知
    void on_changed(Listener listener);
};
```

`set` 里有一处小气但重要的判断：

```cpp
if (new_value == value_) {
    return;
}
```

**值没变就不通知**，于是不会为一次"写了等于没写"的赋值安排重画。

**一次会自己往上走的失效请求**：

```cpp
void Widget::invalidate() {
    // A rectangle is relative to the parent, so a node cannot compute its own
    // screen area yet. The whole client area is repainted instead: the M1
    // simplification, with damage regions arriving in M2.
    const Widget* root = this;
    while (root->parent_ != nullptr) {
        root = root->parent_;
    }
    if (root->repaint_ != nullptr) {
        root->repaint_();
    }
}
```

节点不认识窗口，也不认识平台 —— 它只知道"往上走到根，请根去重画"。**根上那个钩子**由应用安装：

```cpp
root_.set_repaint_handler([this] { invalidate(); });
```

`invalidate()` 是 `Window` 的方法，落到 `InvalidateRect(hwnd_, nullptr, TRUE)`。**框架的"要重画"和平台的"InvalidateRect"在这一行上对接。**

## 落回具象：节点自己接线

那行自己画的字，现在是一个会照顾自己的节点：

```cpp
class DrawnLine : public Widget {
public:
    DrawnLine() {
        text.on_changed([this] { invalidate(); });
    }

    Property<std::wstring> text;
};
```

三行。**接线写在节点自己的构造函数里**，而不是散在各处调用点。于是点击处理变成：

```cpp
// The node owns its text, so writing it also schedules the repaint.
// Forgetting was the whole bug.
drawn_->text.set(kText);
```

而且 `paint()` 直接读 `drawn_->text.value()`。

**这就是那一层的意思：把"记得调 InvalidateRect"从一件要记住的事，变成一件做不到的事** —— 因为写入点根本没有别的出口，写值就是排重画。

## 诚实的一节

**一、现在是整窗重画。** `invalidate()` 走到根之后请根重画整个客户区，而不是那个节点的矩形。原因很实在：**矩形是相对父节点的**，节点自己算不出自己在屏幕上的位置 —— 要算就得沿着父链累加偏移，那是坐标契约的事（控件行为清单 B5 那一格），M1 还没做。所以这里选择了诚实的粗粒度：整窗重画，形状先留着。

**二、`Property` 没有"取消订阅"。** `on_changed` 只能加不能减。M1 里属性的宿主就是订阅者，生命周期一致，没问题；一旦出现"订阅别人的属性"，就需要 `Connection` 那套东西 —— 那属于后面的事。

**三、这一层没有自动化的像素级验证。** 我尝试用 `PrintWindow` 截图对比"点按钮前后那行字有没有变"，但两次截图的基准不稳定（DWM 的窗口淡入会让整片区域逐像素不同），结论不可信。所以这一条**只做到了结构验证**：接线在节点内部、编译通过、端到端点击链路（读输入框 → 更新标签）通过。**"那行字现在会更新了"这句话，请你自己双击跑一次确认。**

## 五条痛点，清空

| # | 痛点 | 解决它的那一层 |
|:--:|:---|:---|
| 1 | 状态无处安放，全是全局变量 | 窗口对象 |
| 2 | 加一个控件要改三处 | 控件树 |
| 3 | 消息处理挤在一个 `switch` 里 | 事件路由 |
| 4 | 位置全靠手算魔数 | 布局 |
| 5 | 状态改了界面不动 | **属性与重画** |

**第 2 步到此结束。** 抽象做完了，但有一件事还没做：回头看看这具骨架和第一篇那个裸版到底差在哪。那是第 3 步的事 —— 把同一个 demo 用框架重写一遍，然后并排对照。

```cpp
/**
 * @file property.h
 * @brief A value that tells listeners when it changes.
 */

#pragma once

#include <functional>
#include <utility>
#include <vector>

/**
 * @brief A value plus the list of things that care about it.
 *
 * A write notifies only when the value actually differs, so a repaint is never
 * scheduled for a write that changed nothing.
 *
 * @tparam T The stored type, comparable with `==`.
 */
template <typename T>
class Property {
public:
    /**
     * @brief The signature a listener has.
     */
    using Listener = std::function<void()>;

    Property() = default;

    /**
     * @brief Build a property with a starting value.
     *
     * @param[in] initial_value The value to start from.
     */
    explicit Property(T initial_value) : value_(std::move(initial_value)) {}

    /**
     * @brief Read the value.
     *
     * @return The current value.
     */
    [[nodiscard]] const T& value() const { return value_; }

    /**
     * @brief Write the value.
     *
     * Notifies every listener, but only when the new value differs from the old
     * one.
     *
     * @param[in] new_value The value to store.
     */
    void set(T new_value) {
        if (new_value == value_) {
            return;
        }
        value_ = std::move(new_value);
        for (const Listener& listener : listeners_) {
            listener();
        }
    }

    /**
     * @brief Add a listener.
     *
     * @param[in] listener Called whenever the value changes.
     */
    void on_changed(Listener listener) { listeners_.push_back(std::move(listener)); }

private:
    T                     value_{};
    std::vector<Listener> listeners_;
};
```

### `framework/widget.h`

```cpp
/**
 * @file widget.h
 * @brief A node in the widget tree.
 */

#pragma once

#include <functional>
#include <memory>
#include <utility>
#include <vector>

#include "framework/event.h"
#include "framework/geometry.h"

/**
 * @brief A node in the widget tree.
 *
 * This layer answers pain point 2. A control used to cost three scattered
 * edits: an id constant, a CreateWindowExW call and a branch in the message
 * handler. Now it costs one node.
 *
 * Layer rule: nothing under framework/ includes windows.h. Anything that owns
 * a native handle lives in the platform layer and derives from this class.
 */
class Layout;

class Widget {
public:
    /**
     * @brief The signature a node uses to install its event handler.
     */
    using EventHandler = std::function<bool(Event&)>;

    Widget();
    virtual ~Widget();
    Widget(const Widget&)            = delete;
    Widget& operator=(const Widget&) = delete;

    /**
     * @brief Take ownership of a child node.
     *
     * @param[in] child The node to attach.
     * @return A reference to the attached child, for chaining.
     */
    Widget& add_child(std::unique_ptr<Widget> child);

    /**
     * @brief Read the node that owns this one.
     *
     * @return The parent, or nullptr for the root.
     */
    [[nodiscard]] Widget* parent() const { return parent_; }

    /**
     * @brief Read the children.
     *
     * @return The owned children, in insertion order.
     */
    [[nodiscard]] const std::vector<std::unique_ptr<Widget>>& children() const { return children_; }

    /**
     * @brief Read the node's identity.
     *
     * @return An id handed out at construction, unique inside the process.
     */
    [[nodiscard]] int id() const { return id_; }

    /**
     * @brief Find a node by id.
     *
     * @param[in] node_id The id to look for.
     * @return The matching node, or nullptr. Searches this subtree depth first.
     */
    [[nodiscard]] Widget* find_by_id(int node_id);

    /**
     * @brief Read the node's rectangle.
     *
     * @return The rectangle, in the parent's coordinate space.
     */
    [[nodiscard]] const Rect& bounds() const { return bounds_; }

    /**
     * @brief Move and resize the node.
     *
     * @param[in] bounds The new rectangle, in the parent's coordinate space.
     */
    void set_bounds(const Rect& bounds);

    /**
     * @brief Install the handler this node runs for events it accepts.
     *
     * @param[in] handler Called with every accepted event; returns true when
     * the handler dealt with it.
     */
    void set_handler(EventHandler handler);

    /**
     * @brief Answer whether this node wants the event.
     *
     * @param[in] event The event on its way through the tree.
     * @return true to let the event reach on_event.
     */
    [[nodiscard]] virtual bool accepts(const Event& event) const;

    /**
     * @brief Handle an accepted event.
     *
     * @param[in] event The event to handle.
     * @return true when this node handled it and bubbling stops.
     */
    virtual bool on_event(Event& event);

    /**
     * @brief Install the strategy that arranges this node's children.
     *
     * @param[in] layout The strategy, or nullptr to remove the current one.
     */
    void set_layout(std::unique_ptr<Layout> layout);

    /**
     * @brief Arrange the children.
     *
     * Runs on its own after every bounds change, so a container never has
     * to remember to lay out again.
     */
    void layout_children();

    /**
     * @brief Read the size this node asks for.
     *
     * @return The hint; a zero component means "whatever the layout decides".
     */
    [[nodiscard]] const Size& preferred_size() const { return preferred_size_; }

    /**
     * @brief Ask for a size.
     *
     * @param[in] size The hint; a zero component means "whatever the layout
     * decides".
     */
    void set_preferred_size(const Size& size) { preferred_size_ = size; }

    /**
     * @brief Ask for a repaint.
     *
     * Walks to the root and calls its repaint hook, so a node that owns a
     * property can refresh itself without knowing the platform exists.
     */
    void invalidate();

    /**
     * @brief Install the hook that turns a repaint request into a real redraw.
     *
     * Set on the root; the window decides what repainting means in its terms.
     *
     * @param[in] handler Called when some node below asks for a repaint.
     */
    void set_repaint_handler(std::function<void()> handler) { repaint_ = std::move(handler); }

protected:
    /**
     * @brief Runs after the bounds change.
     *
     * A subclass overrides this to move whatever native object it owns.
     */
    virtual void on_bounds_changed() {}

private:
    static int              next_id_;
    EventHandler            handler_;
    std::unique_ptr<Layout> layout_;
    Size                    preferred_size_{};
    std::function<void()>   repaint_;

    int                                  id_     = 0;
    Widget*                              parent_ = nullptr;
    std::vector<std::unique_ptr<Widget>> children_;
    Rect                                 bounds_{};
};
```

### `framework/widget.cpp`

```cpp
#include "framework/widget.h"

#include <utility>

#include "framework/layout.h"

namespace {

// Ids start at 1: zero is reserved so a zeroed Win32 control id (or a stray
// default-constructed message parameter) never matches a real node.
constexpr int kFirstId = 1;

}  // namespace

int Widget::next_id_ = kFirstId;

Widget::Widget() : id_(next_id_++) {}

Widget& Widget::add_child(std::unique_ptr<Widget> child) {
    child->parent_ = this;
    children_.push_back(std::move(child));

    // The tree owns the child from here: destroying the parent destroys the
    // whole subtree, with no hand-written teardown anywhere.
    return *children_.back();
}

Widget* Widget::find_by_id(int node_id) {
    if (id_ == node_id) {
        return this;
    }
    for (auto& child : children_) {
        if (Widget* found = child->find_by_id(node_id); found != nullptr) {
            return found;
        }
    }
    return nullptr;
}

bool Widget::accepts(const Event& /*unused*/) const {
    return true;
}

bool Widget::on_event(Event& event) {
    return handler_ != nullptr && handler_(event);
}

void Widget::set_handler(EventHandler handler) {
    handler_ = std::move(handler);
}

Widget::~Widget() = default;

void Widget::set_bounds(const Rect& bounds) {
    bounds_ = bounds;
    on_bounds_changed();

    // A container lays its children out again after every move, so nobody has
    // to remember to call the layout by hand.
    layout_children();
}

void Widget::set_layout(std::unique_ptr<Layout> layout) {
    layout_ = std::move(layout);
    layout_children();
}

void Widget::layout_children() {
    if (layout_ != nullptr) {
        layout_->arrange(*this, bounds_);
    }
}

void Widget::invalidate() {
    // A rectangle is relative to the parent, so a node cannot compute its own
    // screen area yet. The whole client area is repainted instead: the M1
    // simplification, with damage regions arriving in M2.
    const Widget* root = this;
    while (root->parent_ != nullptr) {
        root = root->parent_;
    }
    if (root->repaint_ != nullptr) {
        root->repaint_();
    }
}
```

### `platform/window.h`

```cpp
/**
 * @file window.h
 * @brief A window together with the object that owns it.
 */

#pragma once

#include <windows.h>

/**
 * @brief A window plus the object that owns it, tied so the window procedure
 * can find its way back to the instance.
 *
 * The window procedure is a C callback that knows nothing about `this`, so the
 * object travels through the creation parameters and gets stashed on the window
 * itself. This is the answer to pain point 1 of the concrete pass: state
 * finally has somewhere to live.
 *
 * Parameter names keep the SDK's spelling (msg / wparam / lparam) so this code
 * still reads against the official documentation.
 */
class Window {
public:
    Window()                         = default;
    virtual ~Window()                = default;
    Window(const Window&)            = delete;
    Window& operator=(const Window&) = delete;

    /**
     * @brief Register the window class and create the window.
     *
     * @param[in] instance Module instance handle from wWinMain.
     * @param[in] title Window title, shown in the caption.
     * @param[in] width Initial width in pixels.
     * @param[in] height Initial height in pixels.
     * @return true when the system accepts both steps.
     */
    bool create(HINSTANCE instance, const wchar_t* title, int width, int height);

    /**
     * @brief Show the window and force the first paint.
     *
     * @param[in] show_command One of the SW_* values, usually straight from
     * wWinMain's nShowCmd.
     */
    void show(int show_command) const;

    /**
     * @brief Mark the whole client area for repainting.
     */
    void invalidate();

    /**
     * @brief Read the native window handle.
     *
     * @return The handle, or nullptr before create() succeeds.
     */
    [[nodiscard]] HWND handle() const { return hwnd_; }

protected:
    /**
     * @brief Handle one message.
     *
     * A subclass handles the messages it knows and delegates everything else to
     * Window::handle_message.
     *
     * @param[in] msg Message identifier.
     * @param[in] wparam Message-specific word parameter.
     * @param[in] lparam Message-specific long parameter.
     * @return The value the system expects for this message.
     */
    virtual LRESULT handle_message(UINT msg, WPARAM wparam, LPARAM lparam);

private:
    // The C callback the system calls. It cannot be an ordinary member
    // function: the system knows nothing about `this`.
    static LRESULT CALLBACK window_proc(HWND hwnd, UINT msg, WPARAM wparam, LPARAM lparam);

    HWND hwnd_ = nullptr;
};
```

### `platform/window.cpp`

```cpp
#include "platform/window.h"

namespace {

// The class name must be unique inside the process. One class serves every
// Window instance.
constexpr wchar_t kWindowClassName[] = L"AnatomyGuiWindow";

}  // namespace

bool Window::create(HINSTANCE instance, const wchar_t* title, int width, int height) {
    WNDCLASSEXW window_class{};
    window_class.cbSize        = sizeof(window_class);
    window_class.lpfnWndProc   = &Window::window_proc;
    window_class.hInstance     = instance;
    window_class.lpszClassName = kWindowClassName;
    window_class.hCursor       = LoadCursorW(nullptr, IDC_ARROW);
    // The class brush stays null: the paint handler owns the client area, and
    // letting the system erase first is what makes a resize flash.
    window_class.hbrBackground = nullptr;

    // Registering the same class twice fails. A second window is a supported
    // case, so treat "already there" as success.
    if (RegisterClassExW(&window_class) == 0 && GetLastError() != ERROR_CLASS_ALREADY_EXISTS) {
        return false;
    }

    // The last argument is the only channel that reaches the window procedure
    // before CreateWindowExW returns, so the object travels through it.
    HWND hwnd = CreateWindowExW(0, kWindowClassName, title, WS_OVERLAPPEDWINDOW | WS_CLIPCHILDREN,
                                CW_USEDEFAULT, CW_USEDEFAULT, width, height, nullptr, nullptr,
                                instance, this);
    if (hwnd == nullptr) {
        return false;
    }

    hwnd_ = hwnd;
    return true;
}

void Window::invalidate() {
    InvalidateRect(hwnd_, nullptr, TRUE);
}

void Window::show(int show_command) const {
    ShowWindow(hwnd_, show_command);
    UpdateWindow(hwnd_);
}

// NOLINTBEGIN(performance-no-int-to-ptr)
LRESULT CALLBACK Window::window_proc(HWND hwnd, UINT msg, WPARAM wparam, LPARAM lparam) {
    // WM_NCCREATE is the only message that carries the creation parameters, and
    // it arrives before CreateWindowExW returns. Stash the object pointer here;
    // every later message reads it back.
    if (msg == WM_NCCREATE) {
        auto* create = reinterpret_cast<CREATESTRUCTW*>(lparam);
        auto* self   = static_cast<Window*>(create->lpCreateParams);
        SetWindowLongPtrW(hwnd, GWLP_USERDATA, reinterpret_cast<LONG_PTR>(self));
        self->hwnd_ = hwnd;
        return self->handle_message(msg, wparam, lparam);
    }

    auto* self = reinterpret_cast<Window*>(GetWindowLongPtrW(hwnd, GWLP_USERDATA));
    if (self != nullptr) {
        return self->handle_message(msg, wparam, lparam);
    }
    return DefWindowProcW(hwnd, msg, wparam, lparam);
}
// NOLINTEND(performance-no-int-to-ptr)

LRESULT Window::handle_message(UINT msg, WPARAM wparam, LPARAM lparam) {
    switch (msg) {
    case WM_DESTROY:
        // A destroyed window is not an exiting process: drop WM_QUIT in the
        // queue and let the message loop end on its own terms.
        PostQuitMessage(0);
        return 0;

    default:
        return DefWindowProcW(hwnd_, msg, wparam, lparam);
    }
}
```

### `app/demo.cpp`

```cpp
#include <memory>
#include <utility>

#include "framework/event_router.h"
#include "framework/property.h"
#include "framework/stack_layout.h"
#include "platform/native_widget.h"
#include "platform/window.h"

namespace {

// A leaf that owns the text it paints. Wiring the invalidation inside the
// node is what removes pain point 5: forgetting the repaint stops being
// something a caller can do.
class DrawnLine : public Widget {
public:
    DrawnLine() {
        text.on_changed([this] { invalidate(); });
    }

    Property<std::wstring> text;
};

// The same demo as the concrete pass, with the controls moved into a widget
// tree. Pain point 2 is gone: a control is one node now, and its id, its
// native window and its teardown all follow from that node.
class DemoWindow : public Window {
public:
    void create_controls(HINSTANCE instance);

protected:
    LRESULT handle_message(UINT msg, WPARAM wparam, LPARAM lparam) override;

private:
    // One line per control: no id constant, no CreateWindowExW, no teardown.
    NativeWidget& add_native(DWORD extended_style, const wchar_t* class_name, std::wstring text,
                             DWORD style);

    void layout_controls();
    void on_button_clicked();
    void paint();

    HINSTANCE   instance_ = nullptr;
    Widget      root_;
    EventRouter router_;

    NativeWidget* edit_   = nullptr;
    NativeWidget* button_ = nullptr;
    NativeWidget* label_  = nullptr;

    // A leaf that owns no window: the tree holds it, the layout gives it a
    // rectangle, and paint() draws it. Two kinds of node in one tree.
    DrawnLine* drawn_ = nullptr;
};

}  // namespace

NativeWidget& DemoWindow::add_native(DWORD extended_style, const wchar_t* class_name,
                                     std::wstring text, DWORD style) {
    auto widget =
        std::make_unique<NativeWidget>(extended_style, class_name, std::move(text), style);

    NativeWidget& node = *widget;
    root_.add_child(std::move(widget));
    node.create(handle(), instance_);
    return node;
}

void DemoWindow::create_controls(HINSTANCE instance) {
    instance_ = instance;

    edit_   = &add_native(WS_EX_CLIENTEDGE, L"EDIT", L"", WS_CHILD | WS_VISIBLE | ES_AUTOHSCROLL);
    button_ = &add_native(0, L"BUTTON", L"显示", WS_CHILD | WS_VISIBLE);
    label_  = &add_native(0, L"STATIC", L"（系统画的 STATIC：会自己更新）", WS_CHILD | WS_VISIBLE);

    // What the button does lives next to where the button is created, not in
    // a switch far below. Adding a control and teaching it to react are now
    // the same edit.
    button_->set_handler([this](Event& event) {
        if (event.kind() != EventKind::Click) {
            return false;
        }
        on_button_clicked();
        return true;
    });
    auto drawn = std::make_unique<DrawnLine>();
    drawn_     = drawn.get();
    root_.add_child(std::move(drawn));

    // Each node declares how big it wants to be; the layout decides where.
    edit_->set_preferred_size(Size{.width = 0, .height = 28});
    button_->set_preferred_size(Size{.width = 120, .height = 36});
    label_->set_preferred_size(Size{.width = 0, .height = 32});
    drawn_->set_preferred_size(Size{.width = 0, .height = 32});

    // One line describes the whole arrangement: twenty pixels of padding,
    // eight between neighbours.
    root_.set_layout(std::make_unique<StackLayout>(20, 8));

    drawn_->text.set(L"（这行字是本程序自己画的，还没被更新过）");

    // The root owns the hook that turns "somebody wants a repaint" into a
    // real invalidate on the window.
    root_.set_repaint_handler([this] { invalidate(); });

    layout_controls();
}

void DemoWindow::layout_controls() {
    // No arithmetic is left: hand the root the client area and let the layout
    // walk the tree. The ordering trap is gone with it - a node without a
    // native window simply has nothing to move yet.
    RECT client{};
    GetClientRect(handle(), &client);

    root_.set_bounds(Rect{.left   = 0,
                          .top    = 0,
                          .right  = client.right - client.left,
                          .bottom = client.bottom - client.top});
}

void DemoWindow::on_button_clicked() {
    const std::wstring kText = edit_->text();

    // Output 1: a system-drawn STATIC. SetWindowTextW invalidates the control
    // itself, so the new text appears with no help from here.
    label_->set_text(kText);

    // Output 2: the line painted by paint(). The node owns its text, so
    // writing it also schedules the repaint. Forgetting was the whole bug.
    drawn_->text.set(kText);
}

void DemoWindow::paint() {
    PAINTSTRUCT paint_state{};
    HDC         window_dc = BeginPaint(handle(), &paint_state);

    // Compose the frame off screen and blit it in one go; painting straight
    // into the window DC leaves a visible gap between the two steps.
    RECT client{};
    GetClientRect(handle(), &client);
    HDC     buffer_dc = CreateCompatibleDC(window_dc);
    HBITMAP buffer    = CreateCompatibleBitmap(window_dc, client.right, client.bottom);
    HGDIOBJ previous  = SelectObject(buffer_dc, buffer);

    // WM_ERASEBKGND refuses to erase, so the frame starts here.
    // NOLINTBEGIN(performance-no-int-to-ptr)
    FillRect(buffer_dc, &client, reinterpret_cast<HBRUSH>(static_cast<INT_PTR>(COLOR_WINDOW + 1)));
    // NOLINTEND(performance-no-int-to-ptr)

    // The framework rectangle becomes a Win32 RECT here and only here: this is
    // the seam between the two layers.
    const Rect& node_bounds = drawn_->bounds();
    RECT        native_bounds{.left   = node_bounds.left,
                              .top    = node_bounds.top,
                              .right  = node_bounds.right,
                              .bottom = node_bounds.bottom};

    SetBkMode(buffer_dc, TRANSPARENT);
    DrawTextW(buffer_dc, drawn_->text.value().c_str(), -1, &native_bounds,
              DT_LEFT | DT_SINGLELINE | DT_VCENTER | DT_END_ELLIPSIS);

    BitBlt(window_dc, 0, 0, client.right, client.bottom, buffer_dc, 0, 0, SRCCOPY);

    SelectObject(buffer_dc, previous);
    DeleteObject(buffer);
    DeleteDC(buffer_dc);

    EndPaint(handle(), &paint_state);
}

LRESULT DemoWindow::handle_message(UINT msg, WPARAM wparam, LPARAM lparam) {
    switch (msg) {
    case WM_COMMAND:
        // The window procedure is a translation layer now, not a decision
        // maker: turn the Win32 notification into a framework event and let
        // the router find somebody willing to handle it.
        if (HIWORD(wparam) == BN_CLICKED) {
            if (Widget* target = root_.find_by_id(LOWORD(wparam)); target != nullptr) {
                Event event(EventKind::Click, target);
                if (router_.dispatch(event)) {
                    return 0;
                }
            }
        }
        break;

    case WM_SIZE:
        // Nothing else moves the controls. layout_controls reads the fresh
        // client size straight from the window.
        if (wparam != SIZE_MINIMIZED) {
            layout_controls();
        }
        return 0;

    case WM_ERASEBKGND:
        // Claim the erase and do nothing: paint() owns the whole client area.
        return 1;

    case WM_PAINT:
        paint();
        return 0;

    case WM_DPICHANGED: {
        // Windows suggests a new rectangle and expects SetWindowPos back. The
        // WM_SIZE that follows re-runs layout_controls.
        // NOLINTBEGIN(performance-no-int-to-ptr)
        const auto* suggested = reinterpret_cast<const RECT*>(lparam);
        // NOLINTEND(performance-no-int-to-ptr)
        SetWindowPos(handle(), nullptr, suggested->left, suggested->top,
                     suggested->right - suggested->left, suggested->bottom - suggested->top,
                     SWP_NOZORDER | SWP_NOACTIVATE);
        return 0;
    }

    default:
        break;
    }

    // Everything else, WM_DESTROY included, belongs to the base class.
    return Window::handle_message(msg, wparam, lparam);
}

// Naming exemption: the parameter names follow the winbase.h declaration and
// MSDN.
// NOLINTBEGIN(readability-identifier-naming)
int WINAPI wWinMain(HINSTANCE hInstance, [[maybe_unused]] HINSTANCE hPrevInstance,
                    [[maybe_unused]] PWSTR pCmdLine, int nShowCmd) {
    // NOLINTEND(readability-identifier-naming)
    DemoWindow window;
    if (!window.create(hInstance, L"Anatomy GUI · 抽象 2/5", 720, 480)) {
        return 1;
    }
    window.create_controls(hInstance);
    window.show(nShowCmd);

    // The message loop stays in the application: it is fifteen lines and it is
    // the clearest thing in the file.
    MSG msg{};
    while (true) {
        const BOOL kResult = GetMessageW(&msg, nullptr, 0, 0);
        if (kResult == 0) {
            break;  // WM_QUIT
        }
        if (kResult == -1) {
            return 1;  // failure
        }

        TranslateMessage(&msg);
        DispatchMessageW(&msg);
    }

    return static_cast<int>(msg.wParam);
}
```
